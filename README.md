# 外贸情报局周刊 · Yuni 出品

每周一期的出口选品情报。AI 帮你扫一遍 32 个收款安全的国家，回答两个问题：**现在缺什么，接下来会缺什么**，最后给你一张「品类 × 国家」选品机会榜。

它是一个 AI skill，Claude Code 和 Codex 都能用：装好以后跟 AI 说「出周刊」就出一期，用 Claude Code 的 Mac 上还能每周自动出。

## 为什么做这个

选品最常见的两种做法：跟着感觉走，或者跟着别人说的走。前者容易错，后者往往已经晚了。

这份周刊换一种做法：一个机会，要在消费者、采购方、政策几层信号里同时看到，才算数。周刊只看广度和方向，不做单品深挖；方向定了，再去查具体的买家。

## 机会模型：五个因子相乘

> **机会分 = 消费需求 × 采购需求 × 可达性 × 时机 × 适配度**

### 消费需求
几个国家同时在涨、持续了几周、处在流行的哪个阶段、背后有没有宏观原因。有宏观原因的能持续，没有的多半是社媒爆款，来得快去得也快。

### 采购需求
零售商和品牌在不在扩这个品类、手里的货是多是少、有没有在换供应商。消费者很热，但采购方货已经备足，说明时机未到。

### 可达性
反倾销、关税、认证、专利，任何一道关卡挡住，这个机会就是零。

### 时机
批发下单的窗口开没开：季节、政策截止日、展会看货时间。零售旺季的货，往往 3–6 个月前就下完单了。

### 适配度
跟你自己合不合适。第一次用时回答十来个问题（身份、资金、账期、熟悉的品类、不做什么），按 7 项评分卡打分。**同一周的数据，不同的人拿到的榜单不一样。**

五项是相乘，不是相加：任何一项为零，整体就是零。每项打红绿灯（🟢 强 / 🟡 中 / 🔴 弱 / ❓ 没查到），排好序放在周刊第一屏。

## 信号分四层

- **消费端**：消费者在搜什么、买什么、吐槽什么
- **采购端**：零售商和品牌在扩什么品类、库存周期走到哪、买家什么时候集中看货
- **预测层**：接下来会缺什么。法规强制替换、关税洗牌、季节和节日、突发事件，再用预测市场校准概率
- **风险层**：会不会被卡。贸易救济、关税调查、国家风险评级

32 个国家按国际信用保险机构的国家评级选出，每季度复查。全部用公开数据，出周刊不花钱。

## 和一般的行业资讯有什么不一样

- **每条都能核对**：每个事实、每个数据点都带原始出处，点过去就能看
- **只给有印证的结论**：至少两类独立来源指向同一件事，才标「高」可信度；只有一周的数据，最高标「中」
- **会记账**：信号台账记下每个信号出现了几周，分清持续的趋势和一日游
- **错了照实写**：被数据否定的判断写进「证伪记录」，不悄悄删掉
- **结论在前**：第一屏就是机会榜和行动建议，后面才是支撑的数据
- **说人话**：涨跌一律写百分比，不写倍数，不用行话

## 每期长什么样

- **一、本期观点**：机会榜、行动建议、要闻速览
- **二、市场动向**：消费动向、采购动向、7 个区域速览
- **三、政策风向**：宏观政策、贸易壁垒、国别风险
- **四、编辑部手记**：未来 6 个月的下单日历、证伪记录、下期跟踪

## 安装

需要 [Claude Code](https://claude.com/claude-code) 或 Codex，加上 Python 3.9 以上（Mac 自带）。每周自动出刊目前只支持 Mac 上的 Claude Code；Windows 或 Codex 可以手动出刊。用 Codex 的话，要确认它能联网搜索（采购端、政策这些靠网页搜索）。

**最简单**：把这句话发给 Claude Code 或 Codex：

> 帮我把 https://github.com/lilyfish8579-arch/trade-intel-weekly 装成 skill

**自己装**：

```bash
# Claude Code
git clone https://github.com/lilyfish8579-arch/trade-intel-weekly.git ~/.claude/skills/trade-intel-weekly
# Codex
git clone https://github.com/lilyfish8579-arch/trade-intel-weekly.git ~/.codex/skills/trade-intel-weekly
```

## 怎么用

第一次跟 AI 说 **「出周刊」**，它会先检查电脑环境、建周刊文件夹、问你十来个问题填好选品档案，再问你要不要马上出第一期（大约 20–40 分钟）。第一期没有对比数据，从第二期开始能看出涨跌和持续性。

平时这样说就行：
- **出周刊 / 补一期**：出新一期
- **把美妆去掉，加上户外**：改关注的品类
- **改选品档案**：改你的身份、资金、不做的品类
- **装自动出刊 / 停掉自动出刊**：Mac 上每周自动出
- **我想深挖 XX 品类**：查进口商和采购联系人

## 锁定品类之后

某个品类连着几期排在前面，你决定认真做了，就可以深挖：具体哪些公司在进口、从哪进、进多少，采购找谁。可以接 [信风 AI](https://app.trade-wind.co/cn/login?invitationCode=XQRQVWHDHWV)（收费，可以免费试用）。AI 每次查之前都会先告诉你查什么、要扣多少点，你同意了才查；自动出刊里绝不会调用。

## 要知道的几件事

- 机会榜是**有依据的判断，不是验证过的预测**。信号台账会记下每期的判断，攒满 8–12 周后可以回头看对了几成
- 外部网站改版或限流时，某个数据源可能抓不到，周刊附录会写明哪些没抓到
- 出周刊会用你自己的 AI 额度，自动出刊建议放在夜里或清早
