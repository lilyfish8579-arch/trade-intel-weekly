# 锁定品类后深挖

周刊只看广度和方向。某个品类连着几期排在机会榜前面、周刊主人说「就看这个了」，才进入深挖：具体哪些公司在进口、从哪进、进多少，采购找谁。

## 先用免费的

| 查什么 | 用什么 | 备注 |
|---|---|---|
| 某国某品从哪些国家进口、中国占多少 | ITC Trade Map（trademap.org，免费注册） | 按 HS 编码查，汇总数据，欧盟和加拿大主要靠它 |
| 美国谁在进口 | ImportYeti（importyeti.com） | 美国海运提单，免费，只能在网页上手动查 |
| 专利、外观设计 | Google Patents、欧盟 EUIPO | 仿款之前必查 |
| 认证门槛 | 各国官方网站、认证机构 | |

## 信风 AI（收费，可选）

信风 AI 能让 AI 直接查：
- **海关提单**：按 HS 编码查谁在进口、从哪进、进多少
- **找公司**：按国家、行业、规模筛进口商、批发商、零售商
- **找人**：目标公司的采购、品类经理的公开职业资料和邮箱

要用的话，需要信风账号和 API key，并装好信风的 skill（tradewind-api）。周刊主人还没有账号的，把注册链接给他（可以免费试用）：https://app.trade-wind.co/cn/login?invitationCode=XQRQVWHDHWV

`config.json` 里 `"tradewind": true` 表示周刊主人有信风；是 `false` 就只在「行动建议」里提一句「锁定后可以用信风查进口商」，不调用。

### 调用规矩（必须遵守）

1. **周刊里不调用**，自动出刊里**绝对不调用**。只在周刊主人明确说要深挖某个品类时才用
2. **每次调用前**，先告诉对方：要查什么、为什么查、预计调用几次、预计扣多少点。**对方同意后才调**，调完报实际扣了多少
3. 默认用 `first_match`、每页最多 10 条；不用 `aggregate` 和 `agentic`（扣点多）
4. 接口第一次失败就停下查原因，不要连续重试
5. 命令里拼参数时不要用 zsh 的 `set -- $变量` 拆参数：zsh 默认不按空格拆，参数会整个传进去，白扣点数

### 覆盖范围（2026-09 实测，以信风后台为准）

- 海关提单：**美国有逐票提单**；加拿大、德国、荷兰查不到。欧盟和加拿大市场用 Trade Map 汇总数据
- 扣点：取 10 条提单约扣 1.36 点，查不到不扣

## 不要做的

- 不要用任何工具自动登录周刊主人自己的 LinkedIn 抓人：封控严，账号会被要求重新验证甚至封号。找人用信风，招聘信息看零售商官网招聘页
- 不要用阿里国际站求购信息（RFQ）当买家线索：虚假信息多
