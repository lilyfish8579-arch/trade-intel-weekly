# 自动出刊（只支持 Mac）

两个定时任务，可以只装第一个：

| 任务 | 做什么 | 花不花钱 | 建议时间 |
|---|---|---|---|
| 每天收折扣热榜 | 跑 `deals_collect.py`，攒一周的热帖 | 不用 AI，不花钱 | 每天 21:00 |
| 每周自动出刊 | 先采折扣热榜和亚马逊畅销榜，再用 `claude -p` 按本 skill 出一期 | **会用对方的 Claude 额度**，一期用得不少 | 对方不用电脑的时候，比如周一早上 07:00 |

为什么建议装第一个：折扣站的 RSS 每次只给最新 30 条左右，不每天收，出刊时只能拿到那一刻的热榜。

## 装之前跟对方确认

1. 自动出刊会用他的 Claude 额度。白天要用 Claude 干活的话，放在夜里或清早
2. 到点时电脑要开着；合盖睡眠的话，唤醒后会补跑一次
3. 周刊文件夹不能放在「文稿」「桌面」「下载」里（macOS 会拦）。已经放在里面的，要么挪出来，要么去「系统设置 → 隐私与安全性 → 完全磁盘访问权限」里给 `/bin/zsh` 打开
4. 跑之前 `claude` 命令要能在终端里用，并且已经登录

## 命令

```bash
python3 $SKILL/scripts/install_schedule.py <周刊文件夹> --deals 21:00         # 每天收折扣热榜
python3 $SKILL/scripts/install_schedule.py <周刊文件夹> --weekly 1 07:00      # 每周一 07:00 出刊
python3 $SKILL/scripts/install_schedule.py <周刊文件夹> --status              # 看装了哪些
python3 $SKILL/scripts/install_schedule.py <周刊文件夹> --remove              # 全停
```

星期：1 = 周一 … 7 = 周日。

## 装完验证

装完先手动跑一次采集，确认能跑通：

```bash
python3 $SKILL/scripts/deals_collect.py <周刊文件夹>
```

想马上试一次完整的自动出刊：`zsh $SKILL/scripts/run_weekly.sh <周刊文件夹>`（会用 Claude 额度，先问对方）。

## 出问题看哪

- 日志：`<周刊文件夹>/logs/`，按日期一天一个文件；折扣热榜的在 `deals.log`
- 出刊成功或失败，Mac 右上角都会弹通知
- 自动出刊里**不会**调用信风等收费接口，要花钱查的事会写进「下期跟踪」
