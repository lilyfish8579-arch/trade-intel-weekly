# 首次设置

周刊文件夹里还没有 `config.json` 时走这里。按顺序做，每步做完再往下，别一口气全跑。

## 1. 检查环境

```bash
python3 $SKILL/scripts/check_env.py
```

把结果翻译成大白话告诉对方：哪些现在就能用，哪些要装。
- **pytrends 没装**：购物飙升词和同比这两个消费端主力源用不了。问对方同不同意装，同意了再跑 check_env 里给的那行命令
- **Reddit 没装**：可选，不装也能出刊。对方想装再按 check_env 的提示来，`rdt login` 要对方先在浏览器登录 reddit.com
- **不是 Mac**：只能手动出刊，其他都一样
- **美国官方进口数据没配 key**：可选，不配也能出刊（欧盟、英国、加拿大的进口数据不用 key）。对方想配就这样做，全程免费、约 3 分钟：
  1. 打开 https://api.census.gov/data/key_signup.html ，组织名随便填（例：Personal research），填邮箱，提交
  2. 几分钟后收到邮件，**先点邮件里的激活链接**（打开页面显示 Success 就是激活了，页面上不显示 key）
  3. key 在邮件正文「Your API key is」后面那串斜体字母数字（约 40 位），让对方复制发过来
  4. 存成 `~/.config/trade-intel-weekly/census_key`（只放这一串，不进周刊文件夹），再跑 `python3 $SKILL/scripts/import_stats.py 950300 US` 确认能查到

## 2. 建周刊文件夹

对方已经说了放哪就直接用，**不再问**；没说过才问，默认 `~/外贸情报局周刊`。

> 别放在「文稿」「桌面」「下载」里：想装自动出刊的话，macOS 会拦定时任务读写这几个文件夹。也别放在 /tmp 这类临时文件夹，重启会清空。
> 对方给的路径正好在这些地方：先提醒一句，问要不要换；对方坚持就照用。

```bash
python3 $SKILL/scripts/init_project.py <周刊文件夹>
```

脚本会记住这个路径，以后开新对话不用再问。

## 3. 填选品档案（一次问完）

把下面的问题一次发给对方，有选项的列出选项，对方可以说「跳过」：

1. 你现在是：工厂 / 贸易公司 / SOHO / 跨境卖家 / 还没开始？团队几个人？
2. 你在哪，能找到哪些产业带的工厂？
3. 主要卖给谁（可多选）：进口商和批发商 / 零售连锁 / 品牌商 / 亚马逊等平台 / 独立站
4. 能压多少货款（人民币）：10 万以内 / 10–50 万 / 50–200 万 / 200 万以上
5. 能接受的最长账期：只做预付 / 30 天 / 60 天 / 90 天及以上
6. 已经有的资源：熟悉的品类、合作工厂、认证、老客户？
7. 哪些品类不做？哪些门槛不碰：带电池 / 食品接触 / 儿童用品 / 医疗器械 / 其他？
8. 有没有想多看的品类？（例：小家电、户外、家纺）
9. 有没有特别想做的市场？（填了也照样 32 国一起看，只在分数接近时优先排、卡片上标 ⭐）
10. 评分卡 7 项里，你最看重哪 2 项？（把 `$P/选品档案.md` 里的评分卡表格贴给对方看）
11. 有没有信风 AI 账号？（锁定品类后查进口商和采购联系人用，收费；没有就跳过）

按回答填 `$P/选品档案.md`，写上「最后更新」日期。**对方没说的不要替他编**，写「未填」；一栏里只答了一部分的，没答的那几项也写「未填」（例：已有资源只说了品类和工厂 → 「认证：未填；老客户：未填」），出刊时「未填」不当成「没有」。金额照对方说的写，不换算。

## 4. 按回答调 config.json

- **不做的品类**：从 `shopping_rising.categories`、`amazon_bestsellers` 和 `amazon_new_releases` 里删掉。例：不做美妆 → 删 `"44": "美妆个护"` 和 `"美妆个护"` 那组榜单。「带电池」这类门槛管不到 config，只写在选品档案里，出刊时卡掉
- **想多看的品类**（第 8 题）：
  - Google 购物品类编号：11 家居园艺、951 厨房餐具、271 家用电器、270 家居装饰、948 床品卫浴、158 家装五金、269 园艺、66 宠物、20 运动、688 户外、65 爱好休闲、432 玩具、68 服装、78 消费电子、95 办公用品、44 美妆个护、47 汽车、18 购物综合。每多 1 个品类，购物飙升词多跑约 2 分钟
  - 亚马逊榜单：跟现有各组一样，美英德法四个站各配一个类目地址。地址各站不一样，子类目还带编号，不要凭记忆填，按下面查：
    1. 列类目：`python3 $SKILL/scripts/amazon_bestsellers.py --list US`（一级类目），`--list US kitchen`（kitchen 下面的子类目），在列表里找对应的品类和地址
    2. 试抓：`--test US kitchen/289913`。❌ 的不加；✅ 的还要看输出的页面标题和第 1 名是不是这个品类——子类目编号不对时亚马逊会退回到大类，照样抓得到
    3. 和已有的组重复的不加（例：「家居厨房」组已经抓了 kitchen 大类）
    4. 每次请求间隔几秒，每个地址只试一次
- **Reddit 板块**：第 8 题有想多看的品类，就加消费者讨论买什么、用得怎么样的板块（例：户外加 `CampingGear`、家居加 `HomeDecorating`）；拿不准的不加，没填就不动
- **信风**：第 11 题有账号 → `"tradewind": true`
- 改完把改了什么、为什么告诉对方

## 5. 问要不要装定时（只有 Mac）

读 `自动出刊.md`，把两个选项和花费讲清楚，对方同意才装。

## 6. 收尾

告诉对方：
- 第一期没有对比：畅销榜、信号台账都是从这期开始攒，第二期起才看得出涨跌和持续性
- 周刊在哪个文件夹，用 Obsidian 打开效果最好（卡片能折叠），别的 Markdown 软件也能看
- 想改国家、品类、选品条件，直接跟 AI 说

然后问：**「现在就出第一期吗？大约 20–40 分钟，主要在等 Google 限流。」**对方同意就接着按 SKILL.md 的出刊流程做；不同意就告诉他以后说「出周刊」就行。
